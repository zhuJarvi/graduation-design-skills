# 答辩问题库

先把问题和答案绑定到证据。没有证据的问题不要删掉，而应转化为局限或补充验证计划。

## 研究问题

1. 你的问题为什么真实存在？
2. 这个问题为什么值得做毕业设计，而不是一个普通开发任务？
3. 研究对象和使用场景的边界是什么？
4. 哪些结论不适用于你的场景？
5. 如果重新做一次，你会怎样更早验证这个问题？

## 现有工作与创新

1. 现有方法已经做到了什么？
2. 你的研究缺口是如何从文献比较中得到的？
3. 你的核心贡献能否用一句话说明？
4. 这是方法创新、工程实现、应用创新还是评价创新？
5. 如果删除你的核心模块，结果会发生什么变化？

## 方法

1. 为什么选择这个方法？
2. 与其他候选方案相比，成本和风险是什么？
3. 方法中的关键假设是什么？
4. 哪个模块最容易失败？
5. 你如何确认实现与设计一致？

## 实验

1. 数据从哪里来，是否具有代表性？
2. 训练、验证、测试如何划分？
3. 基线为什么足够强且公平？
4. 指标为什么能反映你要证明的价值？
5. 样本量和重复次数为什么足够？
6. 是否报告失败样本、方差或不确定性？
7. 结果在哪些条件下不成立？
8. 如何排除偶然性或实现错误？

## 系统与工程

1. 系统的主链路是什么？
2. 最关键的稳定性风险是什么？
3. 使用真实数据时会出现哪些额外问题？
4. 系统如何处理错误输入或失败？
5. 当前方案能否扩展到真实规模？

## 学术规范与局限

1. 数据使用是否获得许可或符合要求？
2. 文献和引用的核验方式是什么？
3. 是否使用了生成式工具，如何记录和披露？
4. 你的最大局限是什么？
5. 如果给你多两个月，最优先补哪项证据？
