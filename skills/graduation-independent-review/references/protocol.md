## 角色与独立性

正式独立审查包含两个不可混用的角色：

| 角色 | 可以做 | 不可以做 |
|---|---|---|
| 协调者 | 冻结材料、建立审查包、启动审查者、汇总状态、推动修复 | 代替审查者下结论、修改问题等级、泄露作者预期 |
| 审查者 | 阅读审查包、复现关键步骤、记录问题、给出结论 | 继承父对话、修改源文件、接受未提供证据的解释 |

独立性由上下文、材料和权限共同决定。只是换一个提示词、换一种说法或让同一主智能体“重新检查”，不构成独立审查。

## 协调者准备

### 1. 冻结版本

优先使用 Git 提交、发布包或不可变目录。没有版本控制时：

- 建立只读审查快照；
- 记录文件列表和 SHA-256；
- 记录数据、配置、模型和图表源文件版本；
- 确保审查期间源文件不会被重写。

### 2. 最小化披露

审查者需要事实和标准，不需要作者说服。默认排除：

- 作者已知薄弱点；
- “请确认没有问题”的期待；
- 作者拟定的结论；
- 之前审查的具体问题和结论；
- 与审查无关的聊天记录、周报和个人笔记；
- 未脱敏的凭据、个人信息和受限数据。

作者知识可在独立审查结束后用于对照，不进入第一轮审查包。

### 3. 明确范围

审查包必须说明：

- 审查模式和目标；
- 必须覆盖的文件或步骤；
- 明确不审查的内容；
- 哪些问题属于 P0；
- 学校、导师或项目的强制标准；
- 可运行命令、设备限制和依赖限制。

## 子智能体提示词

协调者用 `spawn_agent` 创建审查者，必须使用 `fork_turns="none"`。提示词保持短而完整，模板见 `assets/reviewer-prompt.md`。

提示词中必须包含：

- 身份：“你是独立审查者”；
- 模式：`formula`、`code` 或 `paper`；
- 技能路径或明确要求加载 `$graduation-independent-review`；
- 审查包绝对路径；
- 输出文件绝对路径；
- 禁止修改源文件和禁止再启动审查者；
- 只依据审查包和其中列明的外部标准；
- 必须给出问题分级和明确结论。

提示词中不得包含：

- 预期审查结果；
- 作者对问题的解释；
- 需要重点“洗清”的内容；
- 前一轮审查结论；
- 父对话摘要或作者私密推理。

启动后先做一次任务接收检查。审查者应明确复述或开始处理审查包、模式和输出文件。若只返回“准备好了”“要做什么”等泛泛回复，或声称工作区为空，说明任务未成功注入：

1. 协调者发送一次完整纠正任务，重复审查包绝对路径、输出绝对路径和禁止修改要求；
2. 仍无实际读取或文件输出时，终止本轮隔离启动；
3. 向用户说明独立审查未能启动，不能降级为同上下文自查；
4. 不根据子智能体的问候或口头承诺生成审查报告。

## 审查者行为

审查者按以下顺序工作：

1. 读取 SKILL.md 和指定模式清单。
2. 核对审查包完整性与版本。
3. 独立重建材料支持的核心声明。
4. 复现关键步骤、运行命令、推导或论文证据链。
5. 寻找反例、缺失假设、不公平比较和不可复现条件。
6. 记录问题、证据位置、影响和建议。
7. 按门槛给出结论。
8. 写出报告和问题表后结束。

审查者不得修改被审查文件。需要作者澄清时，先把问题记录为“材料不足”或“无法验证”；确有必要的澄清由协调者组织补充材料，并产生新的审查版本。

审查者完成任务的最低证据是：报告和问题表都实际存在，内容对应审查包版本，并包含明确结论。

## 结论与问题分级

| 等级 | 判断 | 例子 |
|---|---|---|
| P0 | 核心结论失效或关键路径不可接受 | 核心假设错误、主流程不可运行、论文结论无证据 |
| P1 | 可能改变结论、公平性、复现或答辩判断 | 基线不足、数据泄漏、引用不能支持关键声明 |
| P2 | 不改变核心贡献的完整性和清晰度问题 | 符号不统一、图表标注不完整、局部表述含糊 |

结论必须与问题等级一致：

- 有未关闭 P0：不通过；
- 无 P0、无核心 P1 未关闭：通过；
- 无 P0，只有有明确修复计划的非核心 P1：有条件通过。

## 复审与仲裁

作者修复后，协调者冻结新版本，并用 `followup_task` 请求原审查者复审。复审至少包含：

- 旧版本与新版本；
- 每个问题的关闭证据；
- 受影响区域的回归检查；
- 新结论和新版本标识。

问题关闭必须存在 `resolution`、`verified_by` 和 `verification`。P0 必须实际修复或删除受影响结论，不能以接受风险关闭。

只有当审查者和作者对 P0、核心证据或结论存在实质分歧时，才启动仲裁。协调者向新的无历史子智能体提供：

- 同一冻结材料；
- 争议问题；
- 双方证据；
- 需要判断的具体问题。

不提供任何一方的预期裁决。仲裁者仍输出独立报告和问题表。
